# Lautwimmelbild K

Kleine Web-App für ein lautspezifisches Wimmelbild zum Laut /K/.

## Enthalten

- Comic-Wimmelbild Bauernhof
- 19 klickbare Hotspots
- Sprachausgabe über den Browser / das iPad
- Zählfunktion: gefundene Wörter
- Hilfen ein-/ausblenden

## Start lokal

Die Datei `index.html` im Browser öffnen.

## GitHub Pages

1. Neues GitHub-Repository erstellen.
2. Alle Dateien aus diesem Ordner hochladen.
3. Unter `Settings` → `Pages` → `Deploy from a branch` wählen.
4. Branch `main`, Ordner `/root` auswählen und speichern.
5. Nach kurzer Zeit ist die App über den GitHub-Pages-Link erreichbar.

## Zielwörter

Kuh, Kalb, Katze, Kanne, Kiste, Kette, Kissen, Kuchen, Koch, Kamera, Kerze, Käfer, Karotten, Traktor, Jacke, Rucksack, Zucker, Decke, Becher.
